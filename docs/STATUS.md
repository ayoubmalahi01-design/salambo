# حالة المشروع

## ما أُنجز
- كل الوحدات الوظيفية المذكورة في README (دخول، أدوار، تلاميذ، حضور، تقارير، كراس، تعاميم، محادثات، سجلات طبية، تدقيق، دعوات).
- هوية بصرية جديدة «قوة · سرعة · تدريب»: واجهة داكنة رياضية مع لونين مميّزين (ليموني وبرتقالي)، صفحة دخول بلوحة تعريفية، بطاقة ترحيب في الرئيسية، وشريط تنقّل سفلي على الهاتف.
- أيقونات PWA جديدة (عادية + maskable) و manifest يدعم العربية RTL.
- فحوص آلية: `npm run verify` (ملفات + RLS على كل الجداول + عدم وجود service_role في الواجهة + ترويسات الأمان) و `npm test` (4 اختبارات وحدة).

## ما لم يُجرَّب (يلزم اختباره يدوياً قبل الاستعمال الحقيقي)
- لم يُشغَّل التطبيق مقابل مشروع Supabase حقيقي في هذه المراجعة.
- عزل مؤسستين، ومنع المدرب من قراءة تقارير زملائه، والدعوات (Edge Function)، والوسائط على Android وiPhone: انظر `ACCEPTANCE_TESTS.md`.
- Push Notifications الفعلية غير مفعّلة (إشعارات داخل التطبيق فقط).

## تحسينات مقترحة لاحقاً
- تصدير تقارير الحضور إلى Excel/PDF.
- لوحة إحصاءات أسبوعية للمدرب (نسبة الحضور لكل فصل).
- اختبارات تكامل آلية مع قاعدة بيانات اختبار.
